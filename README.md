# Проект Project_14.1_OOP
## Описание:
Это проект подготавливает ядро для интернет-магазина популярной темы e-commerce.
## Установка:
1. Клонируйте репозиторий:
```git clone https://github.com/Vladimir1987-web/Development-training.git```
2. Установите зависимости:
```pip install -r requirements.txt```
## Использование:
Данный проект состоит из двух модулей: product.py и category.py, в которых созданы классы Product и Category.
От класса Product добавлены два дочерних класса Smartphone и LawnGrass.
